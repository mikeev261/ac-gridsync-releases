# AC-GridSync releases

This repository is the public release channel for AC-GridSync. Published installers and release notes will appear on the [Releases page](https://github.com/mikeev261/ac-gridsync-releases/releases).

No public release has been published yet.

AC-GridSync update notices are advisory. The app can check this repository's latest stable release without signing in. Downloading and installing a release remain your choice.

Development is maintained separately. This repository does not contain the development source history.
